# Chaîne complète de traçabilité

## Intention

Relier tous les éléments d’un dossier décisionnel dans un parcours consultable et vérifiable de bout en bout.

## Chaîne minimale

Constat → besoin → options → risques → preuves → décision humaine → approbations → autorisation → exécution → vérification → révision ou fermeture.

## Exigences

- identifiants stables;
- organisation et propriétaires explicites;
- liens bidirectionnels;
- versions et horodatages;
- auteur de chaque événement;
- règles appliquées;
- preuves utilisées, rejetées ou contradictoires;
- empreintes d’intégrité;
- éléments manquants visibles.

## Règles

Aucune étape ne doit écraser la précédente. La consultation doit permettre de partir d’une décision vers ses preuves et de partir d’une preuve vers toutes les décisions qui l’utilisent.
