# Étape 3 — Examiner les options

## Intention

Comparer plusieurs voies possibles avant toute sélection humaine.

## Données minimales par option

- description;
- avantages;
- inconvénients;
- coûts et capacité nécessaires;
- délais;
- impacts attendus;
- dépendances;
- inconnues;
- possibilité de retour arrière.

## Règles

- inclure l’option de ne rien changer lorsqu’elle est pertinente;
- utiliser les mêmes critères pour chaque option;
- rattacher les affirmations aux preuves disponibles;
- signaler clairement les données manquantes;
- interdire au moteur d’assistance de sélectionner l’option finale.

## Sortie

Une comparaison explicable et prête pour l’analyse des risques.
