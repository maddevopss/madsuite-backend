# API — Continuité cognitive

## Principes

- les données sont isolées par organisation et par utilisateur;
- les recommandations sont explicables et accompagnées de preuves;
- aucune action suggérée n’est exécutable sans confirmation humaine;
- l’utilisateur peut désactiver les recommandations et les rappels.

## Capacités

- fil d’Ariane et reprise du contexte;
- séances et états cognitifs;
- mémoire prospective et rappels;
- résumés, suggestions et explications;
- préférences, audit et contrôle humain.
